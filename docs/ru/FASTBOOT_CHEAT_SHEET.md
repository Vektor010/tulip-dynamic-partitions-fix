## ⚙️ Аппаратные особенности Fastboot на Tulip

Перед выполнением команд важно понимать архитектуру устройства:

| Параметр | Значение на Redmi Note 6 Pro | Практическое следствие |
| :--- | :--- | :--- |
| **Архитектура слотов** | **A-only** (нет слотов A/B) | Команды вида `flash recovery_a` вызовут ошибку. Используется прямое имя: `recovery`, `boot`. |
| **Интерфейс подключения** | USB 2.0 (Micro-USB) | Прошивка чувствительна к портам USB 3.0/3.2 и контроллерам AMD Ryzen. |
| **Флеш-память** | eMMC 5.1 (Sandisk / Micron / Samsung) | Разметка хранится в стандартной таблице GPT (не UFS). |
| **Загрузчик** | Qualcomm Little Kernel (LK / Aboot) | Поддерживает команды `getvar`, `oem device-info`, `boot`. |
| **Anti-Rollback (ARB)** | **Версия 4 (ARB 4)** | Запрещен откат на старые версии официальной MIUI (риск полного окирпичивания). |

## 🔌 Вход в режим Fastboot

### Способ 1. Аппаратный (с кнопок)
1. Выключите смартфон.
2. Одновременно зажмите и удерживайте кнопки **Громкость Вниз (Volume Down)** и **Питание (Power)**.
3. Удерживайте 5–7 секунд, пока экран не завибрирует и не появится изображение зайца в ушанке (или надпись **FASTBOOT**).
4. Отпустите кнопки и подключите кабель к компьютеру.

### Способ 2. Программный (через ADB из запущенной системы)
Если телефон включен, включена отладка по USB и подключен к ПК:
```powershell
adb reboot bootloader
```

## 🔍 Диагностика и проверка состояния (Инспекция)

### 1. Проверка подключения устройства
```powershell
fastboot devices
```
* **Ожидаемый вывод:**
  ```text
  6357460b    fastboot
  ```
  *(Если вывода нет — устройство не распознано. Проверьте кабель и установите [официальные драйверы](../../drivers/README.md)).*

---

### 2. Проверка кодового имени устройства
Защита от случайной прошивки файлов от других смартфонов:
```powershell
fastboot getvar product
```
* **Ожидаемый вывод для Redmi Note 6 Pro:**
  ```text
  product: tulip
  ```
  *(На некоторых глобальных ревизиях может возвращаться `twolip` — обе вариации аппаратно идентичны).*

---

### 3. Проверка статуса разблокировки загрузчика (OEM Unlock)
```powershell
fastboot oem device-info
```
* **Ожидаемый вывод:**
  ```text
  (bootloader)    Device critical unlocked: true
  (bootloader)    Device unlocked: true
  (bootloader)    Charger screen enabled: false
  (bootloader)    Device authorized: false
  OKAY [  0.005s]
  ```
  > [!IMPORTANT]
  > Параметр **`Device unlocked: true`** обязателен. Если значение `false` — загрузчик заблокирован. Любая попытка прошить раздел `recovery` или `boot` завершится ошибкой: `FAILED (remote: Flashing is not allowed in Lock State)`.

---

### 4. Просмотр всех аппаратных параметров загрузчика
```powershell
fastboot getvar all
```
Команда выводит полную конфигурацию: серийный номер, размеры блоков, версию загрузчика, лимит буфера скачивания (`max-download-size`) и статус разделов.

## 🛡️ Проверка Anti-Rollback (Критическая безопасность)

Xiaomi использует аппаратный механизм **Anti-Rollback (ARB)** на базе предохранителей Qualcomm eFuses (QFPROM). Если прошить прошивку с более низким индексом ARB, телефон мгновенно и безвозвратно превращается в «кирпич» (режим Qualcomm HS-USB QDLoader 9008).

### Проверка текущего индекса ARB:
```powershell
fastboot getvar anti
```

* **Интерпретация результата:**
  * `anti: 4` — **Текущий стандарт для Tulip.** Смартфон находится на защищенной версии.
    * ✅ **МОЖНО:** прошивать любые кастомные рекавери (OrangeFox, TWRP), кастомные ядра, любые кастомные прошивки (Android 10–17).
    * ✅ **МОЖНО:** прошивать официальные Fastboot-прошивки MIUI с `anti: 4` (MIUI 10, MIUI 11, MIUI 12).
    * ⛔ **КАТЕГОРИЧЕСКИ ЗАПРЕЩЕНО:** прошивать через Fastboot старые официальные архивы MIUI (ранние сборки MIUI 9/10), где индекс равен `anti: 3` или отсутствует!
  * `anti:` (пусто) или `getvar: anti failed` — загрузчик не поддерживает переменную (редко на очень ранних ревизиях).

## 📥 Установка и запуск Recovery

### 1. Прошивка рекавери в постоянную память (eMMC)
```powershell
fastboot flash recovery recovery.img
```
* **Ожидаемый вывод:**
  ```text
  Sending 'recovery' (35728 KB)... OKAY [  1.085s]
  Writing 'recovery'...            OKAY [  0.312s]
  Finished. Total time: 1.458s
  ```

---

### 2. Прямой запуск рекавери из оперативной памяти (Tethered Boot)
Умная команда, которая передает образ ядра рекавери в ОЗУ устройства и запускает его **без изменения постоянной памяти**:
```powershell
fastboot boot recovery.img
```
* **Зачем это нужно:**
  1. **Первый запуск после прошивки:** позволяет зайти в кастомное рекавери в обход системного скрипта `/system/bin/install-recovery.sh` стоковой MIUI (который затирает кастомное рекавери обратно на стоковое при обычном старте).
  2. **Аварийный доступ:** возможность сделать бэкап или починить систему без постоянной перезаписи раздела `recovery`.

---

### 3. Правильный переход в рекавери после прошивки
Чтобы зафиксировать кастомное рекавери и не дать стоковой MIUI его перезаписать:
1. Выполните:
   ```powershell
   fastboot flash recovery recovery.img
   ```
2. Сразу же выполните:
   ```powershell
   fastboot boot recovery.img
   ```
   *Альтернатива:* зажмите на телефоне физические кнопки **Громкость Вверх + Питание** и выполните команду `fastboot reboot`. Как только дисплей погаснет, отпустите кнопку Питания, но продолжайте держать кнопку Громкость Вверх до появления логотипа OrangeFox.

## 💾 Прошивка системных и сервисных разделов

> [!CAUTION]
> Прошивайте разделы только файлами, предназначенными строго для Redmi Note 6 Pro (`tulip`). Ошибочная прошивка чужого радиомодуля или загрузчика повредит устройство!

### 1. Прошивка ядра (Kernel / Ramdisk)
Используется при установке кастомных ядер или рутированных образов Magisk/KernelSU:
```powershell
fastboot flash boot boot.img
```

### 2. Прошивка Device Tree Overlay (DTBO)
Требуется на некоторых кастомных прошивках Android 14–17 при обновлении дерева устройств:
```powershell
fastboot flash dtbo dtbo.img
```

### 3. Прошивка радиомодуля (Firmware / Baseband / Modem)
Обновление низкоуровневой прошивки модема (связь, LTE, Wi-Fi, Bluetooth):
```powershell
fastboot flash modem NON-HLOS.bin
```

### 4. Прошивка Hexagon DSP (Цифровой сигнальный процессор)
```powershell
fastboot flash dsp dspso.bin
```

### 5. Прошивка заставки загрузчика (Splash Screen)
Замена первого экрана с логотипом "Mi" (до старта ядра):
```powershell
fastboot flash splash splash.img
```

## 🧹 Очистка и сброс разделов (Wipe)

Команды низкоуровневой очистки разделов eMMC через загрузчик.

### 1. Очистка временного раздела кэша
```powershell
fastboot erase cache
```

### 2. Очистка раздела данных пользователя (Сброс настроек)
> [!WARNING]
> Полностью стирает все пользовательские данные, фото, видео и приложения!
```powershell
fastboot erase userdata
```

### 3. Полный сброс к заводским настройкам (Wipe All Data + Cache)
```powershell
fastboot -w
```
Команда форматирует разделы `userdata` и `cache`. Рекомендуется перед чистой установкой прошивок через рекавери, если возникают проблемы со старыми ключами шифрования.

> [!IMPORTANT]
> **ЧТО НЕЛЬЗЯ ДЕЛАТЬ:**  
> Никогда не выполняйте `fastboot erase system` или `fastboot erase cust` на динамических/retrofit прошивках. Раздел `cust` на Tulip является базовым блочным контейнером для динамических разделов (Retrofit Super). Стирание раздела через fastboot удалит маркеры файловой системы.

## 🔄 Управление питанием и перезагрузка

| Команда | Описание действия |
| :--- | :--- |
| `fastboot reboot` | Стандартная перезагрузка телефона в установленную операционную систему Android. |
| `fastboot reboot bootloader` | Мягкая перезагрузка обратно в режим Fastboot (полезно при смене USB-порта). |
| `fastboot reboot-bootloader` | Синоним команды `reboot bootloader`. |
| `fastboot oem reboot-recovery` | Перезагрузка в режим Recovery (поддерживается на некоторых ревизиях aboot). |
| `fastboot oem edl` | **Перевод в аварийный режим Qualcomm EDL (9008)** без вскрытия задней крышки и замыкания тест-поинтов (Test-Points). |
| `fastboot reboot edl` | Альтернативная команда перехода в EDL режим. |

## 📊 Сводная таблица физических разделов Tulip

Полная карта разделов eMMC смартфона Redmi Note 6 Pro (Snapdragon 636), доступных для взаимодействия через Fastboot:

| Имя раздела | Размер в GPT | Назначение | Можно шить через Fastboot? |
| :--- | :---: | :--- | :---: |
| `recovery` | ~64 МБ | Кастомное или стоковое рекавери (OrangeFox/TWRP) | ✅ **ДА** (`fastboot flash recovery`) |
| `boot` | 64 МБ | Ядро Linux + Initramfs системы | ✅ **ДА** (`fastboot flash boot`) |
| `dtbo` | 8 МБ | Device Tree Blob Overlay для конфигурации железа | ✅ **ДА** (`fastboot flash dtbo`) |
| `modem` | 100 МБ | Образ модема Qualcomm (базовая полоса GSM/LTE) | ✅ **ДА** (`fastboot flash modem`) |
| `splash` | 32 МБ | Логотип начальной загрузки | ✅ **ДА** (`fastboot flash splash`) |
| `dsp` | 16 МБ | Прошивка Hexagon Digital Signal Processor | ✅ **ДА** (`fastboot flash dsp`) |
| `cust` | **830.8 МБ** | Физический раздел (`871366656` байт). База для Retrofit Super | ⚠️ **Только через ZIP/ROM patch** |
| `system` | 3.0 ГБ | Системный раздел (в динамических ROM входит в super) | ⚠️ Шьется через Recovery |
| `userdata` | ~51–110 ГБ | Память пользователя и приложения | ⚠️ Только сброс (`fastboot erase`) |
| `fsg`, `modemst1`, `modemst2` | по 1.5–2 МБ | **EFS (IMEI, калибровки радиомодуля, MAC-адреса)** | ⛔ **НЕЛЬЗЯ ТРОГАТЬ В FASTBOOT** |
| `xbl`, `tz`, `rpm`, `aboot` | по 512К–2МБ | Загрузчики первичного уровня Qualcomm | ⛔ **ОПАСНО (Риск брика)** |

## 🛠️ Устранение типичных сбоев Fastboot

### 1. Зависание на `<waiting for any device>`
* **Причина 1:** Не установлены драйверы WinUSB / Android Bootloader.
  * *Решение:* Запустите [`drivers/install_drivers.cmd`](../../drivers/README.md) от имени администратора.
* **Причина 2 (Критично для AMD Ryzen):** Несовместимость протокола Fastboot с чипсетами AMD (B450/B550/X570) и портами USB 3.0/3.1.
  * *Решение:* Подключите телефон строго в **черный порт USB 2.0** на задней панели ПК (напрямую в материнскую плату). Если на ПК только USB 3.0 — используйте недорогой **USB 2.0 Hub (разветвитель)** между ПК и телефоном.

### 2. Ошибка `FAILED (remote: Flashing is not allowed in Lock State)`
* **Причина:** Загрузчик телефона заблокирован.
* *Решение:* Разблокируйте загрузчик через официальную утилиту Xiaomi Mi Unlock Tool.

### 3. Ошибка `FAILED (remote: Partition table doesn't exist)` или `No such partition`
* **Причина:** Попытка прошить несуществующий раздел (например, ввод команд от устройств с разметкой A/B: `fastboot flash recovery_a`).
* *Решение:* На Tulip нет суффиксов `_a` или `_b`. Шейте строго по имени: `recovery`, `boot`.

### 4. Ошибка `FAILED (remote: data too large)` или `max-download-size exceeded`
* **Причина:** Размер прошиваемого файла превышает объем буфера ОЗУ загрузчика.
* *Решение:* Проверьте целостность файла. Образ recovery для Tulip не должен превышать 64 МБ (обычно около 30–45 МБ).
