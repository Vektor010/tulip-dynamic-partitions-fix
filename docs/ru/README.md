## ⚡ Краткая суть проекта

1. **Проблема 1 (Ошибка при установке — Error 1):**  
   Кастомные сборки Android 15–17 часто собираются общими для двух моделей (Whyred и Tulip). В файле разметки прописан размер раздела `cust` от Whyred (832 МБ), а на Tulip он аппаратно равен 830.8 МБ. Рекавери прерывает установку.  
   👉 **Решение:** Коррекция метаданных `unsparse_super_empty.img` под реальный размер Tulip.

2. **Проблема 2 (Перезагрузка в рекавери после прошивки):**  
   Ядро Linux 4.19 на новых версиях Android требует шифрование `fscrypt v2`. Стандартный раздел ext4 часто форматируется без поддержки необходимых флагов, из-за чего служба `vold` падает при первой загрузке.  
   👉 **Решение:** Перевод разделов `/data` и `/cache` в файловую систему **F2FS**.
