# 📲 Установка Recovery и прошивка (OrangeFox / TWRP)

[🇬🇧 English Version](../en/RECOVERY_INSTALLATION.md) | [📚 К оглавлению](README.md)

Это руководство содержит подробные инструкции:
1. **Как установить само рекавери (OrangeFox / TWRP) на телефон с компьютера через Fastboot.**
2. **Как правильно установить прошивку через рекавери и настроить F2FS.**

---

## 📥 Часть 1: Установка Recovery на телефон через Fastboot

Если на телефоне всё ещё стоит заводское рекавери от MIUI или вы устанавливаете кастомное рекавери впервые.

### 📋 Что понадобится:
1. **Разблокированный загрузчик:** надпись «unlocked» с открытым замком внизу экрана при включении телефона.
2. **Установленные драйверы Fastboot:** запустите [`drivers/install_drivers.cmd`](../../drivers/README.md) от имени администратора.
3. **Утилиты ADB и Fastboot:** установленные на ПК (например, через `winget install Google.PlatformTools` или распакованные `platform-tools`).
4. **Файл рекавери:** скачайте актуальный образ для **Redmi Note 6 Pro (Tulip)**:
   * **OrangeFox Recovery** (рекомендуется) — архив `OrangeFox-*.zip`. Распакуйте из него файл `recovery.img`.
   * **TWRP Recovery** — файл `twrp-*-tulip.img` (переименуйте в `recovery.img` для удобства).

---

### 🔌 Пошаговые команды Fastboot:

#### Шаг 1. Перевод телефона в режим Fastboot
1. Полностью выключите смартфон.
2. Зажмите и удерживайте одновременно кнопки **Громкость Вниз** и **Питание** (Volume Down + Power).
3. Держите их 5–7 секунд, пока на экране не появится оранжевая надпись **FASTBOOT** (или заяц Xiaomi в ушанке).
4. Подключите телефон кабелем Micro-USB к компьютеру (рекомендуется использовать чёрный порт USB 2.0 на задней панели ПК).

#### Шаг 2. Проверка подключения в консоли
Откройте PowerShell или Командную строку (CMD) в папке, где лежит файл `recovery.img`, и выполните:
```powershell
fastboot devices
```
> **Ожидаемый результат:** отобразится серийный номер вашего устройства и статус, например:  
> `6357460b    fastboot`  
> *(Если список пуст — проверьте драйверы и кабель, см. [руководство по драйверам](../../drivers/README.md)).*

#### Шаг 3. Прошивка рекавери в физический раздел
Выполните команду записи образа в раздел `recovery`:
```powershell
fastboot flash recovery recovery.img
```
> **Ожидаемый результат:**
> ```text
> Sending 'recovery' (35728 KB)... OKAY [  1.120s]
> Writing 'recovery'...            OKAY [  0.345s]
> Finished. Total time: 1.512s
> ```

#### Шаг 4. Первая загрузка в кастомное рекавери
> [!CAUTION]
> **КРИТИЧЕСКИ ВАЖНО: ЗАЩИТА ОТ ЗАТИРАНИЯ СТОКОВОЙ MIUI!**  
> Если после прошивки рекавери просто перезагрузить телефон в обычном режиме, заводская система MIUI при первом старте **автоматически перезапишет кастомное рекавери обратно на стоковое**!  
> Необходимо СРАЗУ ЖЕ загрузиться в только что прошитое рекавери.

Запустите временную прямую загрузку из памяти:
```powershell
fastboot boot recovery.img
```
*(Либо: зажмите и удерживайте на телефоне физические кнопки **Громкость Вверх + Питание** и выполните команду `fastboot reboot`. Как только экран погаснет, отпустите кнопку Питания, но продолжайте держать Громкость Вверх, пока не загорится логотип OrangeFox/TWRP).*

#### Шаг 5. Закрепление OrangeFox в системе (Для OrangeFox)
Если вы скачивали OrangeFox в виде ZIP-архива:
1. После успешной первой загрузки в OrangeFox скопируйте полный архив `OrangeFox-*.zip` на карту памяти MicroSD или внутреннюю память телефона.
2. В интерфейсе OrangeFox перейдите во вкладку **Files (Файлы)** ➔ выберите `OrangeFox-*.zip` ➔ проведите свайп для установки (**Swipe to Install**).
3. Рекавери автоматически прошьёт все служебные скрипты выживания (Fox Survival Engine) и перезагрузится обратно в постоянный OrangeFox.

## 🦊 Часть 2: Установка прошивки через OrangeFox (Рекомендуется)

OrangeFox является наиболее стабильным и продвинутым рекавери для архитектуры Retrofit Dynamic Partitions на Redmi Note 6 Pro.

### Шаг 1. Перенос архива на телефон
* **Вариант А (Флешка):** Скопируйте пропатченный ZIP-архив на карту памяти MicroSD или подключите USB-OTG флешку.
* **Вариант Б (ADB Sideload):** Оставьте файл на ПК, в OrangeFox зайдите в **Меню ➔ ADB Sideload ➔ проведите свайп**, а на ПК выполните:
  ```powershell
  adb sideload "C:\путь\к\прошивке-tulip-fixed.zip"
  ```

### Шаг 2. Прошивка архива
1. На главном экране перейдите на вкладку **Файлы** (иконка папки).
2. Выберите файл `ИмяПрошивки-tulip-fixed.zip`.
3. Проведите свайп вправо (**Swipe to Install**).
4. Дождитесь завершения процесса. В конце должно появиться сообщение:  
   `Success` / `Process ended with signal: 0`.

### Шаг 3. Перевод Data и Cache в F2FS (Защита от бутлупа)
> [!IMPORTANT]
> **НЕ НАЖИМАЙТЕ REBOOT SYSTEM СРАЗУ ПОСЛЕ УСТАНОВКИ!**
1. Нажмите иконку **Меню** (три горизонтальные полоски в правом нижнем углу).
2. Выберите пункт **Manage Partitions (Управление разделами)**.
3. Нажмите на раздел **Data**.
4. Нажмите кнопку **Change FS (Сменить файловую систему)**.
5. Выберите **F2FS** и проведите свайп внизу (**Swipe to Apply**).
6. Вернитесь на один шаг назад, нажмите на раздел **Cache**.
7. Нажмите **Change FS ➔ выберите F2FS ➔ проведите свайп**.

### Шаг 4. Финальный сброс данных (Format Data)
1. Перейдите во вкладку **Wipe (Очистка)**.
2. Нажмите кнопку **Format Data**.
3. Введите с клавиатуры слово `yes` и нажмите синюю галочку подтверждения.
4. После завершения очистки нажмите **Reboot System**.

## 🔷 Способ 2: В TWRP Recovery

1. На главном экране TWRP нажмите **Install**.
2. Выберите архив прошивки и проведите свайп для установки (**Swipe to confirm Flash**).
3. После завершения вернитесь на главный экран: нажмите **Wipe ➔ Advanced Wipe**.
4. Поставьте галочку **ТОЛЬКО** возле пункта **Data** (не проводите свайп!).
5. Нажмите кнопку **Repair or Change File System** внизу.
6. Нажмите **Change File System** ➔ выберите **F2FS** ➔ проведите свайп (**Swipe to Change**).
7. Вернитесь назад, отметьте галочкой раздел **Cache**.
8. Нажмите **Repair or Change File System ➔ Change File System ➔ выберите F2FS ➔ свайп**.
9. Вернитесь в главное меню **Wipe ➔ нажмите Format Data ➔ напишите `yes` ➔ Enter**.
10. Нажмите **Reboot ➔ System**.

---

## ❓ Что делать, если в рекавери нет пункта F2FS?
Если при выборе файловой системы кнопка F2FS неактивна или выдаёт ошибку `mkfs.f2fs not found`:
* Ваша версия рекавери устарела.
* Скачайте и прошейте актуальную версию **OrangeFox Recovery R11.1+** для Tulip / Whyred.
