# 🔌 Драйверы Fastboot и ADB для Redmi Note 6 Pro (Tulip)

В этой папке собраны официальные, подписанные цифровой подписью драйверы для корректного распознавания смартфона в Windows 7, 8.1, 10 и 11.

---

## 📁 Содержимое папки

| Папка / Файл | Описание | Подпись |
| :--- | :--- | :--- |
| **`install_drivers.cmd`** | ⚡ **Установщик в 1 клик** (автоматически регистрирует все INF-пакеты в хранилище драйверов Windows через `pnputil`). | — |
| **`xiaomi_usb_driver/`** | Официальные драйверы **Xiaomi Technology, Inc.** для режимов Fastboot (`VID_2717`), ADB, Recovery и MDB. | Microsoft Windows Hardware Compatibility / Xiaomi |
| **`google_usb_driver/`** | Официальные драйверы **Google USB Driver (r13)** для AOSP Fastboot и Android Composite ADB Interface. | Microsoft Windows Hardware Compatibility / Google LLC |

---

## 🚀 Способ 1: Автоматическая установка в 1 клик (Рекомендуется)

1. Кликните правой кнопкой мыши по файлу **`install_drivers.cmd`** и выберите **«Запуск от имени администратора»** *(или просто запустите двойным кликом — скрипт сам запросит повышение прав)*.
2. Скрипт добавит оба набора драйверов в систему Windows.
3. Готово! Теперь при подключении телефона в Fastboot или Recovery система автоматически применит нужный драйвер.

---

## 🛠️ Способ 2: Ручная установка через «Диспетчер устройств»

Если вы подключили телефон, а в Windows он отображается с жёлтым восклицательным знаком ⚠️ (`Android`, `Other devices` или `Kedacom USB Device`):

1. Нажмите клавиши **Win + X** на клавиатуре и выберите **Диспетчер устройств** (или нажмите **Win + R**, введите `devmgmt.msc` и нажмите Enter).
2. Найдите устройство с жёлтым значком ⚠️ (в разделе *Другие устройства* или *Android Device*).
3. Нажмите по нему правой кнопкой мыши ➔ **Обновить драйвер**.
4. Выберите: **«Найти драйверы на этом компьютере»** (Browse my computer for drivers).
5. Нажмите: **«Выбрать драйвер из списка доступных драйверов на компьютере»** (Let me pick from a list...).
6. Нажмите кнопку **«Установить с диска...»** (Have Disk...) ➔ нажмите **«Обзор»** (Browse).
7. Перейдите в папку `drivers\xiaomi_usb_driver\` и выберите файл **`android_winusb.inf`**.
8. В появившемся списке выберите:
   * Для режима **Fastboot (загрузчик)**: `Android Bootloader Interface` (или `Xiaomi Fastboot Interface`).
   * Для режима **ADB / Recovery**: `Android Composite ADB Interface`.
9. Нажмите **Далее** и подтвердите установку. Жёлтый значок исчезнет!

## ⚠️ Решение частых проблем

### 1. Fastboot не видит телефон на материнских платах AMD Ryzen (USB 3.0 / 3.1)
* **Симптом:** При вводе команды `fastboot devices` консоль пустая или зависает на `waiting for device`.
* **Причина:** Контроллеры USB 3.0/3.1 на материнских платах AMD (B450, B550, X570 и др.) некорректно обрабатывают старый протокол Fastboot USB 2.0.
* **Решение:**
  1. Подключайте кабель **только в чёрные порты USB 2.0** на задней панели материнской платы (не используйте синие порты USB 3.0 и переднюю панель корпуса).
  2. Если портов USB 2.0 нет — подключите телефон через любой обычный недорогой USB 2.0 хаб (разветвитель).

### 2. Ошибка «Не удалось проверить цифровую подпись»
Драйверы в этой папке подписаны официальными сертификатами `Xiaomi Technology, Inc.` и `Google LLC` (`.cat` каталоги присутствуют). Они без проблем устанавливаются на 64-битные Windows 10 и Windows 11 при включенном Secure Boot.
